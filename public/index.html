常见问题

关于安全、费用与使用方式

Token 会被上传到 LLM 对话里吗？ +

不会。Token 仅保存在用户本地的 ~/.ai-deploy-skill/config.json 文件中，权限 0600。Skill 在执行时直接读取本地文件，不经过对话输出，也不通过 LLM。

Skill 会修改我的项目代码吗？ +

绝不修改。Skill 只做「扫描 + 提示」，所有写入操作都限定在自己的临时目录（如 /tmp/deploy-*.zip），不会触碰用户项目。

检测到 127.0.0.1 还能继续部署吗？ +

默认会阻断（退出码 2），等用户修复或显式 --force 强制继续。但 127.0.0.1 部署后外网无法访问，建议改为 0.0.0.0。

支持哪些 Agent？ +

Skill 通过 npx skills（vercel-labs）分发，已实测兼容 Claude Code / Cursor / Cline / Amp / Codex 等 15+ 主流 Agent。

本机调试模式怎么用？ +

通过环境变量指定后端地址：
DEPLOY_API_BASE=http://localhost:3000 node index.js。适合本地调试和演示。
