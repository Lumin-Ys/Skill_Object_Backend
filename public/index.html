FAQ

还有疑问？

关于安全、费用与使用方式

注册之后就能用 Skill 吗？ +

不能。注册只创建控制台账号。必须购买套餐并仍在有效期内，才会签发 Skill Token；没有 Token，Agent 无法调用部署。

Skill 和普通脚本有什么区别？ +

脚本是固定流程；Skill 是工具说明与操作指南。Agent 会根据上下文选择命令、处理异常、调整步骤。

Token 会被上传到 LLM 对话里吗？ +

不会。Token 仅保存在本地 ~/.ai-deploy-skill/config.json，权限 0600。执行时直接读取本地文件，不经过对话，也不经过 LLM。

Skill 会修改我的项目代码吗？ +

绝不修改。只做「扫描 + 提示」，写入操作限定在临时目录，不会触碰用户项目。

检测到 127.0.0.1 还能继续部署吗？ +

默认阻断（退出码 2）。可用 --force 强制继续，但外网无法访问，建议改为 0.0.0.0。

为什么还需要人工确认？ +

创建资源、开放端口、远程执行都可能带来费用与安全影响。人工确认保留否决权，也划定执行边界。

支持哪些 Agent？ +

通过 npx skills 分发，已兼容 Claude Code、Cursor、Cline、Amp、Codex 等 15+ 主流 Agent。

本机调试模式怎么用？ +

指定后端地址：DEPLOY_API_BASE=http://localhost:3000 node index.js
